_REACT Task Force website redesign

Design + WordPress build · Public sector site

Problem

This task force, is an organization investigating cybercrimes like cryptocurrency scams, pig butchering scams, ID theft, and high-tech crime, that had an outdated website that needed frequent updates, but was not accessible to non-technical staff. They relied on the webmaster to update the site.

Constraints

Public information only
Site was scoped to crime-related information, not a blog
Non-technical staff
Content needed to be manageable without engineering support

Approach

Built and designed the site in WordPress so staff could have content autonomy, prototyping early layout and navigation directions with Claude to quickly compare options before finalizing the design in Figma and implementing it in WordPress.

Result

With that autonomy, the task force was able to provide timely updates, news, and informative crime-related scam alerts in real time.

Reflection

The task force has been excited about having the ability to control the content on the new design.
