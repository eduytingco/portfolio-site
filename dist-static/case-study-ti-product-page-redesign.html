TI Product Page Redesign

Design + Thymeleaf build · Enterprise marketing site

Problem

TI's product page had a confusing layout and lacked clear navigation for customers.

Constraints

Public information only
Site was scoped to public product information, not internal documentation
Non-technical staff
Content needed to be manageable without engineering support

Approach

Built and designed the page in Thymeleaf templating purposes for easier maintenance to add new content without the need for a developer.

Result

Page had a better flow, making it easier for customers to find related products and make ordering parts easier.

Reflection

With the redesign, the product page is now easier to navigate and has a better flow for customers to find related products. As well as the ability to add new content without the need for a developer.
